## Note 1 Section 1
### Vex CS Level 1

### Blocks
---
### Key Terms and Definitions
| Term | Definition | Example / Notes |
|--|--|--|
| Hat Block | A block that contains a command | Drive Forward |
| Stack | A block that contains commands, this one is just stacked up | Drive Forward but stacked up 15 times |
| C-Block | A block that "claps" around other blocks | If/Then, Loop, etc |
| Reporter Block | A block that returns numbers | It returns a number |
| Boolean Block | Yes/No Block | It's not that complicated, just a yes/no block is all |
| Repeat Block | A block that loops commands until a certain amount of loops is met | Can be fitted with a Reporter block |
| Wait Until Block | Waits until a certain amount of time has passed | Useful for exact timing |
| If Then Block | If x event is TRUE, then y is executed | The building blocks of advanced decision making |
| Forever Block | Repeats indefinitely | The first most choice for a program that needs to loop forever |

### Concepts
---
### Key Terms and Definitions
| Term | Definition | Example / Notes |
|--|--|--|
| Sequence | The order of instructions | VERY important |
| Parameters | The values going into instructions | Important for a dynamic program |
| Loops / Iteration | The act of repeating | For when a program needs to fire  multiple times |
| Sensors | Adds in world data into the program | Can do many things, e.g., sense color, distance, etc. |
| Booleans & Conditions | Yes / No situations | E.g., is target [RED]? If yes, x, if no, y |
| Sense → Think → Act | Robot senses something, processes it, and then does something | An algorithm  |
| Comparisons | Evaluating two different situations | It decides to pick which one to use |
| Coordinates | It's position | GRID SQUARE 425 012; BEARING 299 |
| Conditionals | Code that will run when something happens | Wall in the way, then x thing will occur |
| Patterns | Loops with an order of sequence | Repeating squares, repeating loops, etc. |
