### Key Terms and Definitions
| Term | Definition | Example / Notes |
|--|--|--|
| Hat Block | A block that contains a command | N/A |
| Stack | A block that contains commands, this one is just stacked up | N/A |
| C-Block | A block that "claps" around other blocks | If/Then,  |
| Reporter Block | A block that returns numbers | It returns a number |
| Boolean Block | Yes/No Block | It's not that complicated, just a yes/no block is all |
| Repeat Block | A block that loops commands until a certain amount of loops is met | Can be fitted with a Reporter block |
| Wait Until Block | Waits until a certain amount of time has passed | Useful for exact timing |
| If Then Block | If x event is TRUE, then y is executed | The building blocks of advanced decision making |
| Forever Block | Repeats indefinitely | The first most choice for a program that needs to loop forever |
